# 씨앗 v2 — 스프링과 함께 하는 레퍼런스 기술 모음

> v1에 **형식 표준** 섹션을 추가한 버전. 본문(주제·동기·의도·9장 매핑)은 v1과 동일.

## 이 책은 뭐다

스프링 생태계의 **9개 실전 레퍼런스 기술**을 한 서비스에 얹어 가는 책. 단일 Spring Boot 애플리케이션이 실제 기업 환경에서 마주치는 인증·캐시·파일·이벤트·검색·스트리밍을 거쳐 성장 여정을 따라 움직인다. 조각난 예제가 아니라, 하나의 서비스를 9단계로 키우는 이야기.

## 독자

Spring Boot 기본 문법과 REST API는 이해했지만, Redis·S3·Elasticsearch·RabbitMQ 같은 **주변 인프라를 처음 붙여 보는 주니어/중급 백엔드 개발자**.

## 톤·구조 상수

- 이야기 기반 · 통합 흐름 · 캐릭터 삼각 구도
- 주인공 **오픈이** · **팀장**(힌트 제공자) · **동료**(문제 제기자)
- Try/Fail 루프 최소 1회 · 실패부터 시작
- 비유 → 정식 정의 2단계
- 실습 챕터 12단계 포맷 (`.claude/rules/chapter-format.md`)
- 문체: `~합니다` / `~입니다` (`style.md`)
- 이모지 · 수평선 · 라벨형 H2 금지

## 기술 원칙

- 원문 v5 9장의 **실전 예제 코드는 그대로 유지**. 문체와 서사만 각색
- 각 챕터는 **직전 챕터 위에 누적**

## 형식 표준 (v2 신규)

### 언어·코드 컨벤션
- 주 언어: **Java 17 + Spring Boot 3.x**
- 보조: yaml·dockerfile·bash·sql·javascript (프런트 데모)
- TODO 주석: `// TODO: ~합니다`
- 단계 번호: `// 1.` `// 2.` 의무
- 종결어미: 본문은 `~합니다`/`~입니다`. 단계 주석 명사구 예외

### "이것만은 기억하자"
- **반드시 `:::remember` directive** (마크다운 H2 평문 금지)
- 항목 3~5개 + "다음 챕터에서는" 한 줄 예고
- 마지막 챕터(CH09 RabbitMQ)는 **9개 기둥** 회수 + "책을 덮으며" 단락

### 다이어그램 빈도·종류
- 실습 1개당 흐름 다이어그램 최소 1개
- **컨트롤러 진입점 → 서비스 → 외부 시스템(DB/Redis/S3/...) → 응답** 시퀀스를 챕터마다 1번 이상 시각화 의무
- 카탈로그 우선 컴포넌트:
  - `.terminal-log` — Spring 기동 로그·요청 로그
  - `.sp-figure` + `.sp-flow` + `.sp-step` — 단계 흐름 (요청→처리→응답)
  - `.sp-row` (`.accent`/`.warm`/`.info` 변형) — 라벨+값 비교
  - `.sp-compare` (`.bad`/`.good`) — BEFORE/AFTER, A/B 비교
  - `.sp-chip` — Spring·Redis·S3·Lambda 같은 노드 라벨
  - `.sp-callout` — 강조 인용
  - `.pipeline-box` + `.step-card` — 파이프라인 (HLS·이벤트 등)
- 인라인 `style="..."` 0건 · hex 색 직접 박힘 0건
- 색 토큰: Primary(`accent`) · Secondary(`accent-warm`) · Info만. Utility 신규 사용 금지

### 캐릭터 삼각 구도
- 주인공 **오픈이** (실행자, 신입 백엔드 개발자)
- **팀장** (힌트 제공자, 소크라테스식 질문)
- **동료** (문제 제기자, 실사용 피드백)
- 모든 대화 존댓말 통일
