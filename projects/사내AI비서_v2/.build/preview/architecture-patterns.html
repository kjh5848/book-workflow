아키텍처 다이어그램 패턴 카탈로그

챕터에 다이어그램이 필요할 때 이 6가지 패턴 중에서 골라 요청하시면 일관된 시각 언어로 빠르게 작성됩니다. 각 카드 하단의 요청 표현 예를 그대로 사용하시거나 변형해서 쓰세요.

1. 시안 A — Subgraph Container

SCA시스템 전체 구성 (그룹 + 노드 + 화살표)

언제: 시스템 전체 구성을 보여줄 때. 영역(프론트·백·데이터)을 점선 그룹으로 나누고 그 안에 노드를 배치. 외부 사용자(브라우저)와 외부 의존성(MySQL·Redis)을 컬러로 강조.

2. 시안 B — System Boundary + Layer Flow

SCB비유 ↔ 기술 두 레이어 매핑

언제: 비유와 기술을 일대일 매핑해서 보여줄 때. 두 레이어가 같은 4단계로 가로 흐름. 시스템 boundary 라벨 + 가로 화살표.

3. 시안 C — Branch-Merge Flow

SCC입력 → 분기 → 합류 → 출력

언제: 한 입력이 N갈래로 분기됐다가 다시 합쳐져서 최종 출력으로. 파서 분기·전략 패턴·라우팅 등.

4. 시안 D — Side-by-side Compare

SCD좌·우 두 카드 비교

언제: 두 가지 옵션·전략·접근의 장단점을 같은 항목으로 비교. 전체 재인덱싱 vs 증분, OCR vs Vision LLM, LCEL vs ReAct 등.
전체 재인덱싱 모두 지우고 처음부터
+ 구현이 단순
+ 일관성 100%
- 시간·비용 많이
증분 재인덱싱 바뀐 것만 갈아끼우기
+ 빠름
- 추적 필요
- 오염 가능
요청 표현 예 → "시안 D 스타일로 그려 줘. 좌·우 두 카드에 [옵션 A] vs [옵션 B] 장단점을 +/- 라인으로 비교."

SCE챕터별 누적 + 이번 챕터의 NEW

언제: 챕터 마무리에서 "이전 챕터까지 누적된 부분" + "이번 챕터에서 새로 추가된 부분(NEW)"을 한 화면에. 스토리 진화 추적용.

SCF시간축 + 이벤트 (HIT/MISS/EXPIRED)

호출 방법

이 시안집은 어느 책에서든 다음 명령으로 호출할 수 있습니다 (스킬 내장): 

python3 .claude/skills/pub-html-build/build_html.py \
  --project-root projects/<책> \
  --preview architecture-patterns

호출 시 책의 .build/preview/architecture-patterns.html에 자동 복사된 후 브라우저로 열립니다. 실제 다이어그램을 챕터에 적용할 때는 시안 번호(A·B·C·D·E·F)를 명시해 요청하세요.
