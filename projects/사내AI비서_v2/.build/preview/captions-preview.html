오픈스킬북스 시각 단일 진실원

캡션·테두리 룰 프리뷰

이 페이지는 .claude/rules/structure.md의 캡션 룰을 시각으로 보여 주는 단일 진실원입니다. 모든 그림에서 캡션은 그림 박스 밖이 핵심 원칙입니다. wrapper로 <figure> 시맨틱 태그를 사용해 그림 + 캡션을 한 단위로 묶고, 외곽 한 겹은 안쪽 그림 컴포넌트가 담당합니다.

1. 룰 표 — 그림 종류별 wrapper · 외곽 책임

그림 종류 그림 컴포넌트 외곽 한 겹 책임 구조 (캡션은 항상 박스 밖)
이미지
(Gemini·screenshot)		 <img> 이미지 자체 dashed 1px <figure class="chapter-image"> + <img> + <div class="caption">
(또는 마크다운 이탤릭 자동 변환)
HTML 다이어그램
(자체 외곽 있음)		 .parser-flow·.terminal-log·.rag-pipeline-box 등 컴포넌트 자체 컬러 1.5px <figure> + <.parser-flow> + <div class="caption">
HTML 다이어그램
(자체 외곽 없음)		 .sp-row·.sp-step 등 단순 자식 .sp-figure 회색 점선 1px <figure> + <.sp-figure> + <div class="caption">

공통 규칙: 캡션 위 여백 18px(글로벌 .caption) · 캡션은 그림 박스 밖 · 이중 외곽 금지 · 존댓말 · 가운데 정렬 · 그림 N-N: 콜론 접두어 금지(마침표만).

2. 정상 케이스 (3가지)

GOOD · A1

이미지 캡션 — <figure class="chapter-image"> + 이미지 + 캡션

언제: Gemini·screenshot으로 받은 PNG/JPG 이미지. 마크다운 본문에 ![](경로) 다음 줄에 *그림 N-N. 설명* 이탤릭 — 빌드 시 <figure class="chapter-image">로 자동 묶임.

![](../assets/CH01/01_chapter-opening.png)
*그림 1-1. 환각이 시작되는 장면*
GOOD · A2

HTML 다이어그램 (자체 외곽 있음) — <figure> + .parser-flow + 캡션

언제: .parser-flow처럼 자체 컬러 외곽을 가진 다이어그램. <figure> wrapper는 외곽 없음, 캡션은 컴포넌트 형제로 박스 밖에 위치.

<figure>
  <div class="parser-flow">...</div>
  <div class="caption">그림 N-N. ...</div>
</figure>
GOOD · A3

HTML 다이어그램 (자체 외곽 없음) — <figure> + .sp-figure + 캡션

언제: .sp-row·.sp-step처럼 자체 외곽이 없는 단순 자식. .sp-figure가 회색 점선 외곽 한 겹을 그리고, 캡션은 <figure> 안 .sp-figure 형제로 박스 밖에 위치.

<figure>
  <div class="sp-figure">
    <div class="sp-row">...</div>
  </div>
  <div class="caption">그림 N-N. ...</div>
</figure>

3. 잘못된 케이스 (3가지)

⚠️ BAD · B1

캡션이 박스 안 — .sp-figure 또는 컴포넌트 안에 캡션 삽입

문제: 캡션이 그림 컴포넌트 안에 들어가 있어 그림의 일부처럼 보임. 그림과 캡션의 분리감이 사라지고, 시각 단위가 모호해짐.
해결: 캡션을 컴포넌트 밖, <figure> wrapper 안에 형제로 위치.

키
값
그림 N-4. 캡션이 sp-figure 박스 안에 갇혀 있습니다 (잘못된 예)
<!-- 잘못 — 캡션이 박스 안 -->
<div class="sp-figure">
  <div class="sp-row">...</div>
  <div class="caption">...</div>
</div>
⚠️ BAD · B2

캡션 위 여백 부족 — margin-top: 4px

문제: 그림과 캡션이 너무 가까워 답답해 보임. 14px도 부족하다는 검수에서 18px로 상향됨.
해결: 글로벌 .caption { margin-top: 18px }을 그대로 사용 (별도 inline-style 강제 금지).

⚠️ BAD · B3

그림 N-N: 콜론 접두어 위반

문제: HTML 파이프라인은 자동 번호를 부여하지 않으므로 수동 번호 형식(그림 N-N. 마침표)이 룰. 콜론(:) 사용 금지.
해결: 그림 N-6: ... → 그림 N-6. ....
