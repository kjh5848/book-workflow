## 상세 (서브에이전트 보고서 요약)

### 질문 1. 서사 연속성 — ✅ PASS

각 절 사이 문제-해결 연쇄가 명확. 1.1→1.2→1.3→1.4→1.5 전환마다 캐릭터 대사로 다리. 원형 서사 완성: 도입 동료 대사("ChatGPT한테 물어보면 되지 않나요") → 결말 동료 대사("이제 진짜 AI 비서 같은데요").

### 질문 2. 캐릭터 등장 — ⚠ CONDITIONAL_PASS

팀장 3회(123, 130, 225), 동료 6회, 오픈이 1회. 팀장이 line 225 이후 재등장 없음. 결말이 동료의 검증만으로 닫혀 도입에서 미션 제시했던 팀장이 결말에 부재.

### 질문 3. 비유 회수 — ✅ PASS

"오픈북 시험·사서·도서관·교재" 4개 비유가 도입부 → 기술 파트 → `:::remember`로 3단계 회수. "사서" 비유는 line 307·326·341·350·360·415·455·574까지 8회 등장하며 청킹 설명까지 일관.

### 질문 4. 종결어미 톤 — ✅ PASS

금지 패턴(`~봅시다·~봅니다·~고요·~구요`) 0건. `~합니다 40% / ~습니다 36% / ~입니다 16% / ~세요 8%`로 균형. 같은 어미 4문장 이상 연속 없음.

### 질문 5. 캐릭터 대사 톤 — ✅ PASS

팀장 3건(`~해요`), 동료 6건(`~나요·~네요·~요`), 오픈이 1건(`~요`) 모두 존댓말 일관. `~고요`·반말·`야` 호칭 없음.

### 질문 6. 용어 첫 등장 — ❌ FAIL

LLM(line 6), 컨텍스트(line 7), RAG(line 8), 벡터(line 90), ChromaDB(line 91)가 한국어(English) 형태와 비유/정의 없이 첫 등장. `:::goal` 박스가 영어 약어로 시작해 첫 진입 장벽 높음.

### 질문 7. 용어 정리 표 — ⚠ CONDITIONAL_PASS

표 6개 항목과 본문 핵심 6개 1:1 대응. 다만 본문에 정식 정의(`:::term-box`)가 있는 **사슬 추론(Chain-of-Thought)**·**그라운딩(Grounding)**이 표에 누락. 표에만 있고 본문에 없는 용어는 0건.

### 질문 8. 실습 코드블록 앞 안내 — ✅ PASS

5개 실습 / 6개 코드블록 모두 표준 형식 충족. 파일 경로(`ex01/step1_fail.py` 등) 백틱 + "TODO의 `pass`를 지우고 아래 코드를 작성합니다" 명문이 1~3줄 안에 모두 있음. [실습 3]은 동일 파일의 두 블록을 "같은 파일의 다음 TODO" 방식으로 자연스럽게 연결.

### 질문 9. 코드 후 설명 — ⚠ CONDITIONAL_PASS

step3(1·2)·step5는 "왜" 1문장 + term-box까지 충실. 그러나 step1(temperature=0 의도)·step2(프롬프트 직접 주입의 의미)·step4(청킹 필요성)는 "왜 이 구조"가 약함.

### 질문 10. 섹션 전환 — ⚠ CONDITIONAL_PASS

H2 절 전환(1.1→1.2→1.3→1.4→1.5)은 캐릭터 대사·내면독백으로 잘 연결. 다만 **H3 진입 (1.3 → 1.3.1)** 과 **코드 설명 → 실행 (line 490 → 499)** 다리 문장이 약해 "이제 무엇을 하나" 신호가 부족.
